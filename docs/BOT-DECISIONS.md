# 人機出牌決策帳本

使用者回報過、已經定案的出牌原則。**改人機前先查這份**：新回報跟哪一條衝突，就把兩邊攤開跟使用者討論，
定案後改那一條，並在「修改紀錄」寫為什麼改。不能默默蓋掉，否則會變成 A 蓋 B、C 又蓋 A。

- **嚴重度**
  - 不行：失手也不准。執行力低可以換另一種做法，但不能做蠢事。
  - 不划算：想清楚時要很少發生。
  - 偏好：機率傾向，不強求。
- **題號**：`src/game/botScenarios.json` 的情境題，`npx vitest run botScenarios` 會跑。「單元測試」指的是 `bossAI.test.ts` 裡手寫的題目。
- **大方向（使用者 2026-11-03）**：多數決定要看局面，例如對手對決區有幾疊、各幾張，第幾手，比分，自己的特殊卡資訊。要寫成「依局面給分數 / 機率」，不要寫成「一律怎樣」。真正寫死的只有「不行」等級。
